# Book manager

Android app for managing a book collection. Supports adding, editing, and deleting books, with each entry showing its details in a list.

## Tech stack
- Kotlin
- Android SDK
- Room database (DAO)
- Fragments
- RecyclerView (adapter)

## Getting started
1. Open the project in Android Studio
2. Wait for Gradle sync to finish
3. Click Run
